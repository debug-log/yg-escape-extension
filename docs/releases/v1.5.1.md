## 업데이트 확인 한도 우회

- 업데이트 확인이 GitHub REST API 요청 한도에 영향을 받지 않도록 고정된 최신 버전 메타데이터를 먼저 조회합니다.
- 새 릴리스에 버전, ZIP 크기, SHA-256이 포함된 `update.json`을 함께 게시합니다.
- 고정 메타데이터를 사용할 수 없는 이전 릴리스에서는 기존 GitHub API 확인 방식으로 자동 전환합니다.

`v1.5.0`의 키이스케이프·플레이33 예약 오픈 일정, 카운트다운 기능을 모두 포함합니다.

현재 업데이트 화면이 요청 한도 오류를 표시하면 [최신 버전 다운로드 페이지](https://github.com/debug-log/yg-escape-extension/releases/latest)에서 `yg-escape-extension-1.5.1.zip`을 받아 기존 설치 폴더에 덮어쓴 뒤 Chrome 확장 관리 화면과 예약 페이지를 새로고침하세요. 이후 버전부터는 업데이트 화면이 요청 한도를 우회합니다.
