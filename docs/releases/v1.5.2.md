## 예약 화면을 더 간결하게

- 키이스케이프의 큰 예약 오픈 안내 패널을 제거하고 기존 달력 안에서 오픈 정보를 확인하도록 정리했습니다.
- 달력 날짜의 상세 오픈 안내는 두 줄 툴팁으로 표시하고, 오늘 오픈을 앞둔 날짜에만 오픈 시각을 직접 표시합니다.
- 오픈 표시가 달력 행 높이나 기존 선택 스타일을 바꾸지 않도록 조정했습니다.
- 플레이33 예약 선택 영역을 기존 페이지와 어울리는 간결한 형태로 바꾸고, 상세 안내는 필요할 때만 펼칠 수 있게 했습니다.
- 설정 화면에서는 플레이33 연결 상태와 예약 페이지 이동을 한 영역에 모아 다음 행동을 더 분명하게 표시합니다.
