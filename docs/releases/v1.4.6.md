## 플레이33 예약 선택 패널

- 예약 정보 입력 페이지에 지점·테마·날짜·시간 선택 패널을 추가했습니다.
- 건대·홍대·대전·수원 10개 테마의 조사 시간표를 사용해 `branch`, `theme`, `date`, `time` 값을 변경합니다.
- 원래 값 복원, 요일별 시간 목록 갱신, 모바일 배치를 지원합니다.
- 확장 설정에서 `https://play33.kr`를 사이트로 등록한 뒤 예약 페이지를 새로고침하면 표시됩니다. 기존 인원·요금·안내는 변경하지 않으며, 공휴일·실시간 잔여석은 반영하지 않습니다.

## 일부 파일이 차단돼도 업데이트 계속

- 파일 적용이 실패하면 해당 파일만 건너뛰고 나머지를 계속 적용합니다. 성공한 변경을 자동으로 되돌리지 않습니다.
- 재시작 후 미적용 파일 목록과 배포 ZIP 다운로드 안내를 표시하고, 팝업에서도 목록을 다시 열 수 있습니다.
- 미적용 파일 다시 적용 시 이미 일치하는 파일은 건너뜁니다. 백업은 수동 복구용으로 유지합니다.
- manifest까지 갱신하지 못하면 실제 디스크에 남아 있는 버전으로 재시작합니다. 일부 파일이 미적용된 상태는 전체 업데이트 완료와 구분해 표시합니다.

## 설치 및 알려진 문제

`yg-escape-extension-1.4.6.zip`을 사용하세요. 기존 확장을 제거하지 않고 같은 설치 폴더에 파일을 덮어쓴 뒤 `chrome://extensions`에서 확장을 새로고침하면 설정이 유지됩니다.

이전 버전의 업데이터는 여전히 실패 시 자동 복구할 수 있습니다. 이 변경을 처음 적용하는 업데이트가 실패하면 ZIP으로 수동 설치해야 합니다.

일부 Windows 환경에서 Microsoft Defender가 `update.js`를 탐지·격리하는 문제는 해결되지 않았습니다. 이번 변경은 보안 검사를 우회하지 않으며, 차단된 파일의 적용을 보장하지 않습니다. 일부 파일이 빠지거나 이전 버전으로 남으면 관련 기능이 동작하지 않을 수 있습니다. 수동 설치도 같은 차단이 발생할 수 있습니다.
