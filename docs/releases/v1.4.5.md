## 업데이트 화면 개선

- 버전 확인, 업데이트 실행, 완료 안내를 하나의 흐름으로 정리했습니다.
- 설치 폴더는 처음 연결할 때 안내하고, 연결 이후에는 접힌 설정에서 변경합니다.
- 원래 페이지 새로고침을 선택할 수 없는 경우 이유를 표시합니다.
- 변경 없는 파일은 다시 쓰지 않으며, 업데이트 실패 시 복구 처리와 패키지 검증을 보강했습니다.

## 알려진 문제

일부 Windows 환경에서 Microsoft Defender가 `update.js`를
`Trojan:Win32/Fauppod.A!cl`로 탐지하여 설치 또는 자동 업데이트를 차단할 수 있습니다.
이 버전은 해당 탐지를 해결한 버전이 아닙니다. 개발 PC에서는 무해한 최소 샘플도
같은 탐지를 일으켰으며, 정확한 원인은 아직 확정되지 않았습니다.
차단이 발생하면 업데이트를 중단하고 정상 동작하는 기존 설치를 유지하세요.
수동 설치도 같은 차단이 발생할 수 있습니다. 보안 기능 해제나 예외 등록은 권장하지 않습니다.
