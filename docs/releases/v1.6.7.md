# v1.6.7

- 키이스케이프 시간표를 GitHub의 공통 데이터에서 자동 갱신합니다. 시작 시와 6시간 주기로 확인하며, 오류가 나면 마지막 정상 데이터를 유지합니다.
- 사용자 설정과 직접 수정하거나 삭제한 규칙을 보존합니다. 이름만 바꾼 규칙은 시간표를 계속 갱신합니다.
- 이어도사나 토·일 시간표를 추가했습니다. 미확인 금요일은 추가하지 않았습니다.
- 키이스케이프 www 주소에서도 같은 설정을 사용할 수 있습니다.
- GitHub용 확장 업데이트 기능과 Chrome 웹스토어용 패키징을 분리했습니다. 양쪽 모두 동일한 시간표 데이터를 사용합니다.
- 래빗홀 예약 입력 페이지에 지점·테마·날짜·시간 변경 패널을 추가했습니다.
- 홍대점의 행운만물상·두껍아 테마 시간표를 지원합니다. 토·일 추가 회차도 반영합니다.
- 변경한 예약 정보 표시와 원래 값 복원, 사이트별 사용 설정을 제공합니다.
- 예약일 7일 전 오후 11시 오픈 안내를 제공합니다.

시간표는 2026년 11월 17~23일 확인 기준이며 공휴일·실시간 잔여석은 반영하지 않습니다. 테마 변경 시 인원·요금은 처음 선택한 테마 기준입니다. 미오픈 날짜는 사이트 서버에서 거절되며 자동 제출하지 않습니다.

이번 버전으로 확장을 한 번 업데이트하면 이후 확인된 키이스케이프 시간표는 확장 재설치 없이 갱신됩니다. 새 테마 지원이나 기능 변경은 확장 업데이트가 필요합니다.
