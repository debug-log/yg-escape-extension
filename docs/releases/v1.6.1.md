## 예약 화면 복원과 변경 내용 표시 개선

- 키이스케이프·플레이33에서 다시 나타난 큰 오픈 일정 카드를 제거하고, v1.5.4의 간결한 예약 화면을 복원했습니다. 기능별 켜기·끄기는 유지합니다.
- 키이스케이프 달력은 기존 크기와 선택 스타일을 유지하며 작은 표시·툴팁으로 오픈 정보를 안내합니다. 달력이 새로 그려지면 다음 주기까지 기다리지 않고 바로 표시합니다.
- 플레이33 상단에 ‘아래 예약 정보 변경’ 안내를 추가했습니다. 선택한 날짜·시간·테마가 아래 예약일·테마명에도 즉시 반영되며, 바뀐 항목 옆에 ‘변경됨’ 표시가 나타납니다.
- 원래 값으로 복원하거나 예약 선택 기능을 끄면 아래 예약 정보도 원래 표시로 돌아갑니다. 인원·요금은 처음 선택한 테마 기준으로 유지됩니다.
