## 사이트 등록과 기본 기능 안내 개선

- 팝업에 현재 사이트 추가 버튼을 추가했습니다. 현재 열린 HTTP/HTTPS 사이트의 접근 권한을 요청하고 등록합니다.
- 설정 화면에서 플레이33의 4개 지점·10개 테마와 기본 시간표를 확인하고 바로 활성화할 수 있습니다.
- 일반 응답 규칙 만들기와 키이스케이프 기본 템플릿을 구분했습니다. XHR·fetch 응답 변경은 등록한 사이트에서 사용할 수 있는 공통 기능입니다.
- 팝업의 날짜 제한 해제는 키이스케이프에서만, 플레이33 예약 선택 안내는 플레이33에서만 표시됩니다.
- README에 Windows 보안 차단 종류별 확인 방법과 설정 안내를 추가했습니다.

## 업데이트

확장의 업데이트 화면에서 적용하거나 `yg-escape-extension-1.4.8.zip`을 기존 설치 폴더에 덮어쓴 뒤 확장을 새로고침하세요. 대상 웹페이지도 새로고침하면 변경 사항이 적용됩니다.

일부 Windows 환경의 Defender 탐지 문제는 해결되지 않았습니다. 미적용 파일이 있으면 업데이트 화면의 목록을 확인하세요. 플레이33 기본 시간표는 2026.11.02~08 조사 기준이며 공휴일·실시간 잔여석은 반영하지 않습니다.
