## 키이스케이프 이어도사나 평일 시간표 추가

- 백산방역의 ‘미명도감: 이어도사나’를 기본 시간표 규칙에 추가했습니다.
- 공식 응답으로 확인한 평일 6개 시간대(12:30, 14:10, 15:50, 17:30, 19:10, 20:50)를 월–목에 적용합니다.
- 금·토·일 시간표는 아직 확인되지 않아 대체 규칙에 포함하지 않았습니다.
- 기존 설치에서도 업데이트 후 새 규칙이 추가되며, 사용자의 기존 설정은 유지됩니다.

이번 릴리스는 GitHub 직접 설치 및 업데이트용입니다. Chrome 웹 스토어 배포는 포함하지 않습니다.
