## 예약 도우미 화면과 조작 정돈

- 설정 첫 화면에서 키이스케이프·플레이33을 사이트별로 시작하고 관리합니다. ‘사용 시작’은 접근 권한을 요청한 뒤 해당 사이트의 기본 기능을 함께 켭니다.
- 팝업에서 현재 사이트의 예약 도우미와 기능별 스위치를 조정합니다. 사이트 전체를 껐다 켜도 이전에 선택한 기능 상태를 복원합니다.
- 키이스케이프 기본 시간표와 사용자 응답 규칙을 독립적으로 제어합니다. 범용 규칙 편집과 개발자도구 방해 완화는 고급 설정으로 정리했습니다.
- 기존 설정의 켜짐·꺼짐 상태, 수정한 규칙과 시간표를 보존합니다. 업데이트만으로 꺼둔 기능을 새로 켜지 않습니다.
- 플레이33 예약 선택 패널을 꺼도 오픈 일정 안내만 사용할 수 있습니다. 날짜를 비우면 이전 날짜 대신 날짜 선택 안내를 표시합니다.
- 팝업·설정·업데이트·예약 안내의 용어, 빨간색 강조, 글자·간격·버튼과 키보드 포커스를 맞췄습니다.
- v1.5.4의 지난 날짜·미확인 요일 제한과 v1.5.3의 오래된 업데이트 화면 재시작 수정을 포함합니다.

## 업데이트

확장 프로그램의 업데이트 화면에서 적용하세요. ZIP으로 설치하는 경우 `yg-escape-extension-1.6.0.zip`을 기존 설치 폴더에 덮어쓴 뒤 Chrome 확장 관리 화면과 예약 페이지를 새로고침하세요. 기존 확장을 제거할 필요는 없습니다.

오픈 시각 안내와 저장된 시간표는 실시간 잔여석 확인 결과가 아닙니다. 실제 예약 가능 여부는 각 예약 사이트에서 확인하세요.
