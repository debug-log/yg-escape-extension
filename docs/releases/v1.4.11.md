## 플레이33 예약 선택 토글

- 확장 팝업과 설정 화면에서 플레이33 예약 선택 기능을 켜고 끌 수 있습니다.
- 끄면 예약 선택 변경 패널이 즉시 사라집니다. 패널이 마지막으로 적용한 값이 유지된 경우 원래 예약값으로 복원합니다.
- 꺼짐 설정은 새로고침 후에도 유지되며, 다시 켜면 패널을 사용할 수 있습니다.
- 기존 기본값은 켜짐이며 응답 변경 스위치와 독립적으로 작동합니다.

확장의 업데이트 화면에서 적용하거나 `yg-escape-extension-1.4.11.zip`을 기존 설치 폴더에 덮어쓴 뒤 확장과 예약 페이지를 새로고침하세요.
