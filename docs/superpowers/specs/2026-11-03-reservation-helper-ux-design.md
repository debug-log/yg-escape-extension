# 예약 도우미 UX 정돈

## 승인된 방향

- 제품의 중심은 키이스케이프·플레이33 예약 도우미다. 범용 응답 규칙 관리는 고급 설정에서 제공한다.
- 설정 첫 화면은 사이트별 카드다. 기능 설명과 ‘사용 시작’ 버튼을 제공한다.
- ‘사용 시작’은 해당 사이트 권한을 요청하고 기본 기능을 함께 켠 뒤 켜진 항목을 안내한다.
- 팝업은 현재 사이트의 전체 스위치와 기능별 스위치를 함께 제공한다.
- 사이트 전체를 꺼도 기능별 선택은 저장한다. 다시 켜면 이전 선택을 복원한다.
- 기존 빨간색을 유지하되 색상 사용을 절제하고 글자·간격·버튼·상태 용어를 통일한다.
- 시안의 설정 구성과 기능별 스위치를 추가한 팝업 구성을 승인받았다.

## 화면과 동작

### 팝업

사이트 이름, 도메인, 예약 도우미 전체 스위치, 실제 적용 상태를 표시한다. 키이스케이프는 오픈 일정 안내·날짜 선택 제한 해제·기본 시간표, 플레이33은 오픈 일정 안내·예약 선택 패널을 각각 조정한다. 전체를 끄면 개별 스위치는 기존 선택을 표시한 채 비활성화한다. 적용 상태는 ‘사용 중’, ‘꺼짐’, ‘새로고침 필요’, ‘대상 페이지에서 사용’을 구분한다. 등록 전에는 ‘사용 시작’을 제공한다.

지원하지 않는 일반 사이트에서는 예약 기능을 노출하지 않고 고급 설정으로 안내한다. Chrome 내부 페이지에서는 사용할 수 없는 이유를 표시한다. 개발자도구 방해 완화와 범용 응답 변경은 고급 설정으로 이동한다.

### 설정

‘예약 도우미’와 ‘고급 설정’으로 구분한다. 예약 도우미 화면에는 키이스케이프·플레이33 카드를 동등하게 배치하고 사이트별 시작·중지·세부 기능을 관리한다. 키이스케이프 테마별 기본 시간표는 접어서 제공하고 지점·테마 검색을 유지한다. 범용 규칙 만들기·편집·미리보기, 일반 사이트 등록, 개발자도구 방해 완화는 고급 설정에 둔다. 내부 branch/theme 식별자는 일반 사용자 시간표 설명에서 제거한다.

### 예약 페이지와 업데이트

오픈 일정 위젯과 예약 선택 패널은 확장 화면의 용어·색상·키보드 포커스 기준과 맞춘다. 오픈 시각 안내와 실제 잔여석은 명확히 구별한다. 기존 카운트다운 계산과 예약 폼 복원 동작은 유지한다.

업데이트 화면은 상태 문구와 버튼·간격을 정돈한다. 설치 폴더 연결, 부분 적용 목록, 복구, 파일 검증과 재시작 흐름은 유지한다. Windows에서도 이해할 수 있는 안내를 사용한다.

## 구현 판단과 호환성

- 기존 Chrome 확장 구조와 순수 HTML/CSS/JavaScript를 사용한다. 새 런타임 의존성을 추가하지 않는다.
- 최소 Chrome 111을 유지한다. 플랫폼별 쉘 명령이나 외부 폰트 설치를 제품 흐름에 추가하지 않는다.
- 저장한 사이트·권한·사용자 규칙·이름·시간표·규칙 활성화와 순서를 보존한다. 업그레이드만으로 기능을 새로 켜지 않는다.
- 전체 도우미 스위치는 사이트별 별도 설정으로 저장해 개별 기능과 권한을 지우지 않는다.
- 기본 시간표와 범용 응답 규칙을 구별한다. 기본 시간표만 켤 때 다른 사이트나 사용자 규칙을 함께 켜지 않는다.
- 기존 전역 응답 변경 값은 고급 설정에서 유지하되 ‘사용자 응답 규칙 적용’으로 범위를 명시한다. 새 기본 시간표 설정이 없는 설치는 최초 동기화 때 종전 `config.enabled` 값을 한 번 복사해 저장한다. 이후 두 설정은 독립적이다.
- 기능별 상태 해석은 저장된 선택과 실제 적용을 분리한다. 사이트 전체가 꺼져 있어도 선택은 반환하며, 실제 적용은 사이트 등록·전체 켜짐·개별 켜짐을 모두 확인한다.
- 기본 시간표 규칙은 번들 규칙의 정확한 ID 집합으로 식별한다. 같은 `weekdayFallback` 방식을 쓰는 사용자 규칙은 범용 규칙으로 유지한다.
- ‘사용 시작’은 해당 사이트 기본 기능을 명시적으로 활성화하되, 사용자 규칙을 덮어쓰거나 삭제된 규칙을 무조건 복구하지 않는다. 기본 규칙 복원은 별도 작업으로 유지한다.
- 오픈 일정 안내는 예약 선택 패널과 독립적으로 꺼야 한다. 플레이33 패널 내부에서 생성하는 오픈 위젯도 이를 따라야 한다.
- 플레이33 예약 입력 페이지에서 예약 선택 패널을 꺼도 오픈 일정 안내만 독립적으로 표시할 수 있어야 한다.
- 사이트 전체 도우미 끄기는 기본 예약 기능을 중지하며, 고급 설정에서 사용자가 만든 범용 응답 규칙은 별도로 관리한다.
- 버전 변경·릴리스·배포·원격 push는 이번 로컬 다듬기 범위에 포함하지 않는다.

## 검증 기준

권한 거부 시 설정 불변, 기존 설치 설정 유지, 사이트별 독립 제어, 전체 껐다 켤 때 개별 선택 복원, 동시 설정 저장 보존을 검증한다. 실제 Chrome에서 팝업·설정·예약 페이지 연동과 좁은 화면·키보드 조작을 확인한다. 기존 업데이트·부분 적용·복구·패키징 테스트를 통과해야 한다. Windows 실기 검증은 수행 여부를 명시한다.

## 후속 배포 승인

사용자가 구현 완료 후 배포를 요청했다. 원격 main에 미반영된 최신 릴리스 v1.5.4를 병합하고, 승인된 화면 구성과 기존 요일 제한·업데이트 재시작 수정을 함께 유지해 v1.6.0으로 배포한다. 이전 등록 버튼의 색상만 검사하던 테스트는 실제 확장을 로드해 등록 전후·링크·기능을 검증하는 Windows/Linux 공통 Chrome UI 검사로 대체한다.
