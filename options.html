사용자 응답 규칙

등록한 사이트의 XHR·fetch 응답을 규칙에 따라 변경합니다. 예약 도우미의 기본 시간표는 사이트별 설정을 따릅니다.

등록한 사이트

사이트 추가 후 열린 페이지를 새로고침하세요. HTTP와 HTTPS, 서브도메인은 각각 등록합니다.

응답 규칙

활성화된 규칙 중 위에서 처음 일치하는 규칙 하나를 적용합니다. 기본 규칙 복원은 빠진 키이스케이프 규칙만 추가합니다. 기존 규칙은 유지됩니다.

규칙 편집

빈 배열 []은 모든 JSON에 일치합니다. exists는 경로 존재 여부, equals는 값 일치입니다. 배열 경로는 하나라도 일치하면 충족합니다.
JSON 경로 예시

status, data[0].enable, data[*].enable를 지원합니다. 없는 필드는 새로 만들지 않습니다. 문자열은 큰따옴표로 감싸고 true, false, 숫자는 JSON 타입으로 입력하세요.

02 · 결과 확인
성공 응답에 있는 시간대의 enable을 Y로 변경합니다. 시간대 목록을 붙여넣을 필요가 없습니다.
자동으로 설정되는 조건
이 지점·테마에서 POST run_proc.php 요청에만 적용합니다. 날짜 오류 교체는 해당 오류 문구와 status:false를 확인합니다. 시간대 변경은 status:true인 응답에 적용합니다.


03 · 적용
처음 사용하는 사이트는 Chrome의 접근 권한을 허용해주세요. 저장 후 대상 페이지를 새로고침하면 됩니다.

  

  
표시와 선택을 돕는 기능입니다. 실제 예약은 각 사이트에서 진행합니다. 응답을 변경해도 서버의 예약 상태는 바뀌지 않습니다.
