# 방탈출 예약도우미

방탈출 예약을 돕는 Chrome 확장 프로그램입니다.

## Chrome 설치 방법

1. [최신 버전 ZIP 다운로드](https://github.com/debug-log/yg-escape-extension/releases/latest/download/yg-escape-extension.zip)를 눌러 설치 파일을 받습니다.
2. 받은 ZIP 파일의 **압축을 풉니다**.
3. Chrome 주소창에 `chrome://extensions`를 입력합니다.
4. 오른쪽 위 **개발자 모드**를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
5. 압축을 푼 폴더 중 **`manifest.json`이 들어 있는 폴더**를 선택합니다. 확장 프로그램 목록에 추가되면 설치 완료입니다.

> 설치 후에도 압축을 푼 폴더를 옮기거나 삭제하지 마세요.

주소창 오른쪽의 **퍼즐 아이콘 → 확장 프로그램 옆 핀 아이콘**을 누르면 도구 모음에 고정할 수 있습니다.
