YG Escpae Extension · Chrome 웹 스토어 배포본

개인정보처리방침

시행일: 2026년 11월 6일

YG Escpae Extension은 사용자가 허용한 사이트에서 예약 일정 안내, 날짜·시간 선택, XHR JSON 응답의 표시·처리 변경을 돕는 Chrome 확장 프로그램입니다. 이 방침은 Chrome 웹 스토어 배포본에 적용됩니다.

1. 처리하는 정보와 목적

  • 현재 페이지 주소: 사용자가 확장 팝업을 열면 현재 탭의 주소를 확인하고, 설정 화면에 대상 페이지를 전달하기 위해 브라우저 세션 저장소에 보관합니다. 전체 방문 기록을 조회하거나 별도의 방문 기록 목록을 만들지 않습니다.
  • 허용한 사이트의 웹페이지 내용: 예약 날짜·시간, 지점·테마와 오픈 일정 표시 등 기능에 필요한 페이지 요소를 기기에서 읽고 변경합니다.
  • XHR 요청·응답: 등록하고 접근을 허용한 사이트에서 요청 URL·메서드·본문을 규칙과 비교하고, JSON 응답을 기기에서 읽어 사용자가 켠 규칙을 적용합니다. 사용자 지정 규칙의 대상 응답에는 개인정보가 포함될 수 있습니다.
  • 사용자가 입력한 설정: 등록 사이트, 기능별 선택, 규칙 이름·조건·교체할 JSON·저장된 시간표 등을 로컬에 저장합니다. 사용자가 규칙에 입력한 내용도 저장되므로 비밀번호, 인증 토큰, 연락처 등 민감한 정보를 넣지 마세요.
  • 현재 페이지의 적용 상태: 적용 횟수, 마지막 적용 시각, 규칙 식별자 등의 상태를 페이지 메모리에서 유지하여 팝업에 표시합니다.

2. 저장 위치와 보관 기간

설정과 규칙은 사용 중인 Chrome 프로필의 chrome.storage.local에 저장하며, 확장이 Chrome 동기화 저장소로 전송하지 않습니다. 설정과 규칙은 사용자가 변경·삭제하거나 확장을 제거할 때까지 보관됩니다. 현재 페이지 주소는 chrome.storage.session에 저장하며 새 페이지 정보로 덮어쓰거나 브라우저 세션 종료·확장 다시 로드 시 사라집니다. 응답 변환 결과와 적용 상태는 해당 페이지·요청의 메모리에서 처리하며 개발자 서버에 보관하지 않습니다.

3. 외부 전송과 제3자 제공

이 배포본은 처리한 페이지 주소·내용·XHR 요청·응답·설정을 개발자 서버, 광고 사업자 또는 분석 서비스로 전송하지 않으며, 광고·분석 SDK를 포함하지 않습니다. 사용자 데이터를 판매하거나 광고 타기팅·신용 평가에 사용하지 않습니다.

웹사이트 자체의 네트워크 요청과 사용자가 최종 제출하는 예약 정보는 해당 사이트에서 처리하며 그 사이트의 개인정보처리방침이 적용됩니다. 예를 들어 플레이33 선택 패널에서 바꾼 지점·테마·날짜·시간은 사용자가 예약 폼을 제출할 때 해당 사이트로 전달됩니다. 이 확장은 예약을 자동 제출하지 않습니다. 사용자가 예약 사이트·지원 링크를 열면 해당 서비스에 직접 접속합니다. 설치·자동 업데이트는 Chrome 웹 스토어와 Chrome이 처리하며 Google의 정책이 적용됩니다.

등록 사이트에 주입되는 코드와 설정은 페이지 실행 환경을 공유할 수 있습니다. 응답 규칙과 규칙에 포함된 값은 해당 페이지에서 관찰할 수 있으므로 비밀정보를 규칙에 포함하지 마세요.

4. 권한과 사용자 선택

storage는 설정과 규칙 저장, scripting은 허용 사이트에 필요한 코드 등록, activeTab은 사용자가 연 팝업에서 현재 페이지를 확인하는 데 사용합니다. HTTP·HTTPS 사이트 접근은 선택 권한이며 사용자가 사이트를 추가하거나 사용 시작을 누를 때 해당 사이트의 권한을 요청합니다. 모든 사이트의 접근 권한을 설치 시 일괄 부여받지 않습니다.

5. 열람·변경·삭제

확장의 설정에서 저장된 사이트와 규칙을 확인·변경·삭제할 수 있습니다. 사이트 등록을 삭제하면 해당 사이트의 접근 권한을 철회합니다. 이미 열린 페이지에서 주입 코드를 완전히 제거하려면 페이지도 새로고침하세요. 개별 기능 스위치를 끄는 것은 설정과 규칙의 삭제를 뜻하지 않습니다. 모든 확장 저장 데이터를 제거하려면 Chrome의 확장 프로그램 관리 화면에서 이 확장을 제거하세요.

6. 데이터 사용 제한

사용자 데이터는 위에 설명한 사용자 대면 기능을 제공하는 목적으로만 처리합니다. 이 확장의 사용자 데이터 사용은 Chrome 웹 스토어 사용자 데이터 정책의 제한적 사용(Limited Use) 요건을 준수합니다.

7. 문의와 방침 변경

배포·개발 프로젝트: debug-log/yg-escape-extension. 개인정보 처리와 관련된 문의는 프로젝트 이슈로 접수할 수 있습니다. 공개 이슈에는 이름·연락처·비밀번호·인증 토큰이나 예약 정보가 포함된 응답을 올리지 마세요.

기능과 데이터 처리 방식이 바뀌면 이 문서와 시행일을 갱신하고, 필요한 경우 확장 화면 또는 배포 안내로 변경 내용을 알립니다.
